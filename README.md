🛒 Thoga Kade Shop Management System
📖 Overview

Thoga Kade Shop Management System is a JavaFX desktop application developed to streamline the daily operations of a retail shop named Thoga Kade.
The system enables users to efficiently manage customer, item, supplier, and employee details through an intuitive graphical interface.
It supports full CRUD (Create, Read, Update, Delete) functionality and ensures smooth data handling using TableView and ObservableList components.

🎯 Learning Outcomes

By completing this project, students will be able to:

Design and implement a JavaFX-based GUI for desktop applications.

Perform database CRUD operations from a Java application.

Use TableView and ObservableList to manage and display data effectively.

Apply event handling and form validation techniques in JavaFX.

Manage and organize a Java project using Git and GitHub.

⚙️ Functional Modules
🔐 Login Management

User authentication interface.

Secure login validation before accessing the main dashboard.

👥 Customer Management

Each customer record includes:
Customer ID, Title, Name, DOB, Salary, Address, City, Province, Postal Code
Example: C001, Mr., Danapala, 1981-02-06, 40000, No.20 Walana, Panadura, Western, 12500

📦 Item Management

Each item record includes:
Item ID, Description, Category, Quantity, Unit Price
Example: I001, Red Rice 5kg, Groceries, 40, 1200.00

🏭 Supplier Management

Each supplier record includes:
Supplier ID, Name, Company, Address, City, Province, Postal Code, Contact No, Email
Example: S001, Fernando, Agro Foods Pvt Ltd, No.45 Main Street, Matara, Southern, 81000, 0712345678, agrofoods@gmail.com

👨‍💼 Employee Management

Each employee record includes:
Employee ID, Name, NIC, DOB, Position, Salary, Contact No, Address, Joined Date, Status
Example: E001, Sunil Perera, 832451230V, 1983-07-12, Manager, 75000.00, 0712456789, No.15 Temple Road, Kalutara, 2018-05-10, Active

🧩 Functional Requirements

✅ Create Login Page UI and Functions
✅ Add / View / Update / Delete Customers
✅ Add / View / Update / Delete Items
✅ Add / View / Update / Delete Suppliers
✅ Add / View / Update / Delete Employees
✅ Display data in TableView with proper columns
