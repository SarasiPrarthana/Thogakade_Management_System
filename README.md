🛒 Thoga Kade Shop Management System

📖 Overview

The Thoga Kade Shop Management System is a JavaFX desktop application designed to manage the daily operations of a retail shop named Thoga Kade.
It allows users to efficiently handle customer, item, supplier, and employee information through an intuitive graphical interface.
This system supports full CRUD (Create, Read, Update, Delete) functionality and ensures smooth data management via TableView and ObservableList components.

🎯 Learning Outcomes

By completing this project, students will:
1.Design and implement a JavaFX GUI for desktop applications.
2.Perform database CRUD operations from a Java application.
3.Use TableView and ObservableList to manage and display data.
4.Apply event handling and form validation in JavaFX.
5.Manage and organize a Java project using Git & GitHub.

⚙️ Functional Modules

1. 🔐 Login Management
User authentication interface.
Secure login validation before accessing the dashboard.

2. 👥 Customer Management
Each customer record includes:
Customer ID, Title, Name, DOB, Salary, Address, City, Province, Postal Code

Example:
C001, Mr., Danapala, 1981-02-06, 40000, No.20 Walana, Panadura, Western, 12500

3. 📦 Item Management
Each item record includes:
Item ID, Description, Category, Quantity, Unit Price

Example:
I001, Red Rice 5kg, Groceries, 40, 1200.00

4. 🏭 Supplier Management
Each supplier record includes:
Supplier ID, Name, Company, Address, City, Province, Postal Code, Contact No, Email

Example:
S001, Fernando, Agro Foods Pvt Ltd, No.45 Main Street, Matara, Southern, 81000, 0712345678, agrofoods@gmail.com

5. 👨‍💼 Employee Management
Each employee record includes:
Employee ID, Name, NIC, DOB, Position, Salary, Contact No, Address, Joined Date, Status

Example:
E001, Sunil Perera, 832451230V, 1983-07-12, Manager, 75000.00, 0712456789, No.15 Temple Road, Kalutara, 2018-05-10, Active
